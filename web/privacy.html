Privacy Notice

Last updated: 23 October 2026

Abella Web is the browser interface at https://abella-prover.org/web/, operated by the Abella project maintainers ("we", "us", or "our"). We minimize the data we process and do not use tracking analytics. The prover and editor run in your browser. A small, stateless Cloudflare Worker handles GitHub OAuth token exchange, and Cloudflare and DreamHost provide edge and origin hosting.

1. Data controller

Controller: The Abella project maintainers
Contact: kaustuv@chaudhuri.info
Website: https://abella-prover.org/web/

2. Data we process

A. Project, editor, and local-folder data

Your project files, editor contents, imported source files, and archive contents are handled in your browser. They are not uploaded to, stored on, or processed by our static server.

  • The current project and workspace descriptor may be saved in localStorage so that a reload restores your work.
  • If you use Open folder, the browser's File System Access API reads and writes the files you select. The contents remain on your device and are not sent to us.
  • Import zip and Download zip operate locally in the browser.
  • If you load or commit a GitHub repository, your browser communicates directly with GitHub. See below.

B. GitHub authentication and repository access

GitHub integration is optional. You can use a fine-grained personal access token (PAT) or choose Sign in with GitHub. Abella Web has no user accounts of its own.

  • With OAuth, the main tab sends a short-lived authorization code and a PKCE verifier to the Cloudflare Worker at oauth.abella-prover.org. The Worker exchanges them with GitHub using the OAuth client secret and returns only the access token and granted scope.
  • The Worker does not store, database, or log authorization codes, verifiers, tokens, or the client secret. The client secret exists only as a Cloudflare Worker secret. Cloudflare may process request metadata at the edge as described below.
  • The access token, granted scope, and GitHub login are kept in sessionStorage for the current tab. They are cleared when the tab closes or when you choose Disconnect. The token is never written to localStorage, a URL, a log, or an error message.
  • A PAT entered in the dialog is also kept in sessionStorage and is sent directly to GitHub's API. It is not sent to our static server.
  • The default OAuth scope is public_repo (public repository read and write). If you explicitly enable Allow private repositories, the scope is repo, which is account-wide and covers all repositories you can access. A fine-grained PAT remains the least-privilege option.
  • Repository contents, branches, commits, and account details that you access through GitHub are processed by GitHub, Inc. under the GitHub Privacy Statement. We do not proxy or store repository contents on our servers.
  • You can revoke the OAuth authorization at any time in GitHub Settings → Applications → Authorized OAuth Apps, or by using Disconnect in Abella Web.

C. Network and security metadata

When you request the site or use the OAuth Worker, Cloudflare and DreamHost process limited request metadata to deliver and protect the service:

  • Data: IP address, browser user agent, operating system, requested URL, timestamp, and limited request/response metadata.
  • Purpose: serving static assets, TLS termination, DDoS and abuse protection, the OAuth token-route rate limit, and troubleshooting. The token route is rate-limited by IP for short windows (currently 5 requests per 10 seconds).
  • Legal basis: our legitimate interest in keeping the service secure and available (GDPR Art. 6(1)(f)).
  • Retention: access logs are rotated and are not retained longer than 30 days. We do not maintain application-level user profiles or a database of user activity.

3. Legal bases

  • Local storage that is strictly necessary to provide the editor and the project you requested is used under the ePrivacy Directive's strictly-necessary exception; no consent banner is required for it.
  • GitHub integration is processed to provide the service you request (GDPR Art. 6(1)(b)) and, where consent is the applicable basis, with your consent (Art. 6(1)(a)). You can withdraw consent by disconnecting or revoking the GitHub authorization.
  • Security, rate limiting, and access logs rely on our legitimate interests (Art. 6(1)(f)).
  • We do not intentionally collect special-category data, make automated decisions about you, or sell personal data.

4. Cookies and browser storage

Abella Web sets no first-party cookies and uses no advertising, analytics, or behavioural-tracking services. All application code, styles, and fonts are self-hosted; Cloudflare delivers them at the edge. Cloudflare may set a strictly necessary security cookie at the edge, but we do not use it for tracking.

We use the following browser storage:

  • localStorage: abella.web.v1.project (project and workspace data), abella.web.v1.theme (theme preference), abella.web.v1.sidebar (sidebar preference), and abella.web.v1.github.input (last GitHub repository URL).
  • sessionStorage: abella.web.v1.github.token (GitHub access token) and abella.web.v1.github.meta (granted scope and account login). These are limited to the current tab and cleared on disconnect or tab close.

You can remove local data at any time by clearing this site's data in your browser, or by using Disconnect for the GitHub session.

5. Recipients and international transfers

We use a small number of service providers:

  • Cloudflare, Inc. (DNS, CDN, edge security, rate limiting, and the OAuth Worker) processes request metadata as a processor. See the Cloudflare Privacy Policy.
  • DreamHost hosts the static site and its origin server access logs. See the DreamHost Privacy Policy.
  • GitHub, Inc. processes GitHub account data, authorization decisions, tokens, and repository requests under its own privacy statement linked above. GitHub is not acting as our processor for your GitHub account.

These providers may process data outside your country. Their privacy statements describe the safeguards they use, such as standard contractual clauses or applicable adequacy frameworks. We do not sell personal data or share it for advertising.

6. Retention

  • Local project data and preferences remain in your browser until you clear site data.
  • The GitHub token and account metadata remain in sessionStorage until the tab closes or you disconnect.
  • The OAuth Worker is stateless. Authorization codes, verifiers, and tokens are transient and are not stored by us. Cloudflare rate-limit counters are short-lived.
  • Network access logs are retained for no longer than 30 days, except where a longer period is necessary to investigate a security incident.
  • GitHub retains data according to its own policies.

7. Your rights

If you are in the European Economic Area, the United Kingdom, or Switzerland, you have rights under the applicable data protection law, including:

  • access to your personal data;
  • rectification of inaccurate data;
  • erasure of your personal data;
  • restriction of or objection to processing;
  • data portability;
  • withdrawal of consent, where processing is based on consent;
  • lodging a complaint with your local supervisory authority.

Because most data is stored only in your browser, you can exercise access and erasure directly by viewing or clearing your browser's site data. For requests about transient server or edge logs, contact us at kaustuv@chaudhuri.info. We will respond within one month and may ask for information needed to locate the relevant records. We do not charge a fee for ordinary requests.

8. Security

We use HTTPS, a strict Content Security Policy, a restrictive cross-origin opener policy, an exact-origin CORS allowlist, PKCE for OAuth, a fixed redirect URI, and a stateless Worker. The OAuth client secret exists only as a Cloudflare secret. Tokens are kept in sessionStorage, and codes, verifiers, tokens, and secrets are not logged. No method is completely secure; please report a suspected vulnerability to the contact address above.

9. Children

Abella Web is an educational tool that is not directed at children. We do not create accounts or knowingly collect personal data from children. If you believe a child's data has been processed, contact us.

10. Changes to this notice

We may update this notice if the architecture or legal requirements change. The revision date at the top will be updated, and material changes will be described on this page.

11. Contact

Privacy questions and data protection requests: kaustuv@chaudhuri.info. Non-sensitive project questions can also use the Abella issue tracker.
