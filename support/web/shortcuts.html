Keyboard shortcuts

Checking proofs

Ctrl/Cmd+Enter
Check to cursor
Ctrl+>
Check next command
Ctrl+<
Undo previous command
Ctrl+Shift+]
Continue checking to the end and focus the editor
Ctrl+Shift+[
Reset the prover
Ctrl+.
Focus and scroll to the checked tip
Ctrl+Space
Show command output near the cursor
Ctrl/Cmd+C in the output dialog
Copy all command output

The play and step controls check the active .thm or .thmod tab. Switching tabs does not reset the prover; checking a different file does.

Warnings and other command output appear next to the checked command. Hover the command to read it, or click its marker for the full text.

Editor key bindings

Preferences offers three key binding styles: CUA (the default), Emacs, and Vim.

Ctrl+?
Open the in-app help (CUA and Vim)
Ctrl+h
Open the in-app help (Emacs)

Emacs bindings use Ctrl+a/e/b/f/n/p for movement and Ctrl+_ (or Ctrl+/) for undo.

Vim bindings follow vim defaults. :w saves when saving applies. Ctrl+[ acts as Esc and Ctrl+Space moves by word, so show-output is on Ctrl+Alt+o there.

Project panel

Ctrl/Cmd+B
Show or hide the project panel
↑/↓ in the project panel
Move through files and folders
→/← in the project panel
Expand or collapse folders, or move to the parent
F2 in the project panel
Rename the selected file
Delete in the project panel
Delete the selected file
Shift+F10
Open the actions menu for the selected file or folder

Tab strip

←/→ in the tab strip
Switch between open files

On macOS, use Cmd instead of Ctrl for the Ctrl/Cmd shortcuts. The >, <, and dot shortcuts use Ctrl on every platform.
